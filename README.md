# Yaadhum Enterprises

A responsive, single-page static website for **Yaadhum Enterprises**, a supplier of recycled **PET bottle flakes (chips)**. The site presents the company's recycling process, its product, the industries it serves, a photo gallery of the facility, and contact details.

## Features

The website contains the following sections:

- **Navigation bar** – fixed top bar with the company logo and links to each section, including a "Contact Us" button
- **Hero** – headline, introduction, "Our Product" and "See How It Works" buttons, and key figures (15 KG per bag, 6-step process, 100% quality checked)
- **Process** – the 6-step process from bottle to flake: Collection, Label Removal, Sorting & Cleaning, Crushing Process, Packing, and Supply
- **Product** – Premium PET Bottle Flakes, with feature highlights and 15 KG / bag packaging
- **Why Us** – five cards covering the company's strengths
- **Industries** – the industries served: Plastic Recycling Units, Packaging Industries, Plastic Product Manufacturers, and Raw Material Suppliers
- **Environmental Impact** – the company's sustainability message
- **Gallery** – photos of the facility, from collection to finished PET flakes
- **Contact** – email, phone number, and a "Send Enquiry" button that opens the visitor's email app
- **Footer** – logo, copyright notice, and quick links
- **Scroll-reveal animations** and hover effects, implemented in vanilla JavaScript and CSS
- **Responsive layout** for desktop, tablet, and mobile screens

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- [Google Fonts](https://fonts.google.com/) (Syne and Inter)

No frameworks, build tools, or package managers are used.

## Run Locally

No installation or build step is required.

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in any modern web browser.

An internet connection is needed only to load the Google Fonts; the rest of the site works offline.

## Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository on GitHub and go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select the **main** branch and the **/ (root)** folder, then click **Save**.
5. After a minute or two, the site will be live at `https://<your-username>.github.io/<repository-name>/`.
